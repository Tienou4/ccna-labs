# CCNA Labs

Labs et notes de préparation à la certification **Cisco CCNA (200-301)**.

## Thèmes

- Fondamentaux réseau, adressage IPv4/IPv6, subnetting
- Commutation : VLAN, trunking, STP, EtherChannel
- Routage : statique, OSPF
- Services IP : DHCP, NAT, NTP, SNMP
- Sécurité : ACL, port security, SSH
- Automatisation et programmabilité

## Structure

```
labs/    fichiers Cisco Packet Tracer (.pkt) + énoncés
notes/   fiches de révision
```
